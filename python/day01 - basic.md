##  What is Python?

Python is a high-level, interpreted programming language used to build applications, automate tasks, and process data.

### ⭐ How Python Works

Python code is executed by an interpreter.
 Steps:
- You write code
- Python interpreter reads it line by line
- It executes the code

##### 🔹 Interpreted vs Compiled Language
- Interpreted Language (Python)
- Executes code line by line
- No separate compilation step
- Easier to debug
##### Compiled Language (e.g., C, C++)
- Code is converted into machine code first
- Runs faster
- Requires compilation before execution
  
### ⭐ What is a Variable?

A variable is a container used to store data values. It allows us to store and reuse values in a program.

#### 🔹 Why Variables are Important
- Store data for reuse
- Make code flexible and dynamic
- Help in performing operations
#### 🔹 How Variables Work

In Python, you don’t need to declare a variable type.
##### Example:

name = "Komal"

age = 20 

name and age is variable.
 Python automatically assigns the type.

#### ⭐ Types of Variables (Data Types)
```bash - int → Integer (e.g., 10)
- float → Decimal (e.g., 10.5)
- str → String (e.g., "Hello")
- bool → True/False
 ```

🔹 Example – Hello Program

print("Hello World")

🔹 Example – Sum Program

num1 = 10

num2 = 20

sum = num1 + num2

print(sum)


#### 🔹 Type Casting

Type casting means converting one data type into another.

##### Example:
num = "10"

num = int(num)

print(num)
Converts string "10" into integer 10.
